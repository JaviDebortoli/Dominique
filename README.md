# Dominique
Dominique E Commerce

Pickup-only e-commerce MVP for Dominique (Santiago del Estero, Argentina). Next.js (TypeScript, App Router) + PostgreSQL + Prisma + Tailwind. See `openspec/changes/dominique-ecommerce/` for spec/design/tasks.

## Getting Started

```bash
npm install
npm run dev        # http://localhost:3000
npm run test        # Vitest unit/integration
npm run test:e2e    # Playwright E2E
```

Requires a local PostgreSQL instance; set `DATABASE_URL` in `.env` (see `.env.example`).
